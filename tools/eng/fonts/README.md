# Шрифт листов — DejaVu Sans (в репозитории)

Листы A3 / A4 строятся только этим шрифтом из этой папки, не из системы (разбор 13.11: на Windows без DejaVu Sans
подставился другой шрифт, и строка вышла за рамку). Нет файла — генератор останавливается с ошибкой.

Файлы — из matplotlib 3 (`mpl-data/fonts/ttf`), те же, которыми построен выпуск 6503bf8. Лицензия — `LICENSE_DEJAVU`
(свободная, Bitstream Vera / Arev; распространять можно).
