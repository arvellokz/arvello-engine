## Важно для движка
- Шариковые (боковые) направляющие требуют зазора ~12,5–13 мм с каждой стороны ящика и другой конструкции ящика; скрытые (Samet Smart Slide / Push Open) — дно с выступом и пазом, зазоры по каталогу Samet. Каждая система — свой набор отверстий и размеров ящика → в генераторе система направляющих = опция модели, данные из каталога производителя (Samet, затем шариковые выбранной марки).
- Комод сейчас без ручек (TIP-ON) — для эконом-варианта нужна ручка или push-направляющие.
