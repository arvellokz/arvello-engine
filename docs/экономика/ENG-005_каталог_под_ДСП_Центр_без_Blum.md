# ENG-005: каталог под ДСП Центр, без Blum (задание сессии кода, 14.11.2026)

Решения владельца 13–14.11: ориентируемся на ДСП Центр (Алматы, онлайн-раскрой БАЗИС-Облако); **Blum убрать** (≈ 350 тыс. ₸ на комод), фурнитура — три уровня на выбор клиента; цены пока из интернета. Данные Blum в `docs/blum/` и код под Blum не удалять — сделать опцией.

## 1. Стандарт материалов «ДСП Центр» (профиль поставщика, не правка констант по месту)
- ЛДСП только 16 мм, включая фасады (сейчас фасад 18).
- Кромка только ПВХ: 2×19 на фасадах и видимых передних торцах, 1×19 на остальном (сейчас ABS 2 / ПВХ 0,4).
- ХДФ 3 мм (сейчас 4): проверить шаг крепежа и жёсткость задней стенки.
- Цоколь по умолчанию в цвет корпуса (чёрный лист 16 600 ₸ ради 4 планок). Заодно закрыть вопрос кромки на пласти цоколя (HANDOFF, п. 0) — убрать.
- Декоры — из `docs/поставщики/dspc/ДСП_Центр_база_материалов_2026-11-13.xlsx`; «Дуб натуральный» → Дуб Бунратти 4069 (к Амбергу 4090 нет кромки в цвет).

## 2. Система направляющих — опция модели (три уровня)
| Уровень | Что (artmebel.kz, 14.11) | Открывание |
|---|---|---|
| эконом | MILAT SM 520H 450, скрытые с доводчиком — 1 402 ₸ (или шариковые с доводчиком) | ручка |
| стандарт | MILAT SM FULL SYNCHRO 450, полное выдвижение — 2 901 ₸ | ручка |
| комфорт | Samet PUSH OPEN 450, полное выдвижение + мягкое закрывание — 10 816 ₸ | без ручек |
Размеры ящика, зазоры и отверстия — **только из документов производителя** (Samet, MILAT): чат добывает и кладёт в `docs/фурнитура/`. До этого — не выпускать листы с этими системами как готовые. Ручка — новая деталь (скоба 128/160, отверстия).

## 3. Присадка
По умолчанию сверлит сборщик по листам A4/A3 (ДСП Центр — 220 ₸/отв. Ø5–14, ~40–45 тыс. на комод). Сократить число точных отверстий: оценить конфирмат вместо шкант + эксцентрик там, где не видно. Счётчик отверстий по диаметрам — в манифест (нужен для цены).

## 4. Выгрузка заказа — ENG-004 (`ENG-004_выгрузка_в_БАЗИС-Облако.md`)
CSV на материал для «Загрузить из CSV» + таблица соответствия декоров и кромок. Альтернатива у ДСП Центра: обработка модели БАЗИС-Мебельщика от клиента — 3 000 ₸/проект.

## 5. Себестоимость из движка
`export_cost.py SKU …`: листы целиком (по карте раскроя или площадь × 1,15 → ceil), кромка по толщинам, распил, отверстия, фурнитура по уровням → строка сметы. Сверка с реальной сметой ДСП Центра (комод без столика: 74 065 ₸, `docs/поставщики/dspc/2026-11-14_смета_комод_без_столика.md`).

## 6. Порядок моделей
