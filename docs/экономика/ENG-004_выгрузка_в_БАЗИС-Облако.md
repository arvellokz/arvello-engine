# ENG-004: заказ в ДСП Центр одной загрузкой (задача для сессии кода)

Проблема: ручной ввод 12 строк комода в кабинет занял ~40 минут (материал, размеры, кромка по сторонам через диалоги).

Что умеет кабинет (БАЗИС-Облако ДСП Центра, руководство cdn.bazissoft.ru/documentation/ru/Cloud.pdf, п. 7.2.11 и 8.3.6):
- «Загрузить из CSV» на вкладке «Список панелей» — для **выбранного материала**; схема импорта: разделитель столбцов, со строки N, номера столбцов параметров; толщины кромки из файла сопоставляются с кромкой базы («Новая облицовка» → «Другая…»).
- «Загрузить БАЗИС-модель» на вкладке «Товары» — набор панелей из модели БАЗИС-Мебельщика (форматы в руководстве не названы); п. 8.8 — импорт моделей bCAD и K3.

Сделать:
1. `tools/eng/export_bazis_cloud.py SKU …` → по одному CSV на материал (декор + толщина): длина; ширина; кол-во; кромка L1; L2; W1; W2 (толщина 0 / 1 / 2); текстура (1/0); имя детали. Размеры — готовые с кромкой, длина — вдоль текстуры (как в `export_cutting.py`). Кодировка и разделитель — подобрать по пробной загрузке (Windows-1251 / UTF-8, «;»).
2. Таблица соответствия наших материалов и кромок базе ДСП Центра: `docs/поставщики/dspc/соответствие.csv` (наш декор → наименование в базе; ABS 2 → ПВХ 2×19 в цвет; ПВХ 0,4 → ПВХ 1×19; ХДФ 4 → HDF 3). База материалов — `ДСП_Центр_база_материалов_2026-11-13.xlsx`.
3. Проверка: сумма деталей и метров кромки = CSV выпуска; тест с негативом.
Пробную загрузку в кабинет делает чат (вход — владелец).
