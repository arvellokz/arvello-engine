# Журнал работы Arvello Engine

Общая память всех сессий Claude на всех аккаунтах. Переписка между аккаунтами не видна, а этот файл виден всем.

## Правила

- **Новая сессия** (любой аккаунт): прочитать `HANDOFF.md`, затем последние 10 записей журнала. Остальное открывать только по ссылкам из записей.
- **После каждой законченной задачи:** добавить запись **вверх** списка, 3–5 строк: что сделано, какие решения приняты, что дальше, ссылки на файлы. Затем commit + push. Подробности держать в файлах `docs/`, не в журнале.
- Перед записью сделать `git pull`, чтобы не затереть чужую запись.
- Сессия Claude Code: когда кончился лимит, в той же сессии `/login` другим аккаунтом или `claude --continue`. История сессии хранится на машине, а не в аккаунте.

### 12.11.2026 · чат (аккаунт 1) · решение владельца: независимость от цеха
- **Arvello не подстраивается под один цех:** владелец будет работать с несколькими цехами (дешевле, с ЧПУ). Технологические параметры (паз и зазор дна, засверловка под саморезы, припуски, кромка, мин. размер детали, кто сверлит под Blum) задаём **сами по общепринятым нормам** и проверяем пробой; параметры держать в одном месте модели, чтобы менять за минуты.
- Конструкция должна выдерживать допуск толщины плиты разных поставщиков (ЛДСП 16 — стандарт, не подгонять под один завод).
- Сверление под Blum (крючок, замки) по умолчанию — **наш сборщик по шаблону T65.1000.02**.
- Вопросы цеху сокращены до трёх: (1) в каком виде принимают заказ — PDF / Excel / файл БАЗИС, программа и версия, образец; (2) размеры даём готовые с кромкой — подходит?; (3) проба деталей одного ящика с записью ручных правок. Остальные Ц-0…Ц-12 снять или превратить в наши значения по умолчанию с пометкой [О] (проверить на образце).
