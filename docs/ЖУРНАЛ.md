# Журнал работы Arvello Engine

Общая память всех сессий Claude на всех аккаунтах. Переписка между аккаунтами не видна, а этот файл виден всем.

## Правила

- **Новая сессия** (любой аккаунт): прочитать `HANDOFF.md`, затем последние 10 записей журнала. Остальное открывать только по ссылкам из записей.
- **В конце каждой работы** (даже прерванной): запись **вверх** списка, 3–5 строк, заголовок `### дата · код (аккаунт 1)` / `код (аккаунт 2)` (чат — `чат (аккаунт N)`) · тема. В записи: что сделано, решения, **что не закончено** (строка «Не закончено: …» или «Не закончено: нет»), ссылки на файлы. Затем commit + push в `main`. Подробности — в `docs/`, не в журнале.
- Перед записью сделать `git pull`, чтобы не затереть чужую запись.
- Сессия Claude Code: когда кончился лимит, в той же сессии `/login` другим аккаунтом или `claude --continue`. История сессии хранится на машине, а не в аккаунте.
