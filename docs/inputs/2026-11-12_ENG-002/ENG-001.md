# ENG-001 · Генератор чертежей как свой продукт

Цель: генератор, который быстро и без ошибок выпускает рабочие чертежи для всего каталога (сотни моделей и тысячи вариантов размеров), лучше Blum и Базиса за счёт проверки изделия целиком.

## Перенос (12.11)
- Работа над чертежами переезжает из общего чата в отдельный проект Claude Code.
- Репозиторий: `arvellokz/arvello-engine` (приватный). Создать его должен владелец: у Claude нет прав на создание репозиториев. Локальная копия с историей — `Обмен/ENG/arvello-engine-repo.zip`.
- Всё для продолжения: `Обмен/ENG/Передача — генератор чертежей.md` (тот же текст, что `HANDOFF.md` в репозитории).

## План
1. Справочник фурнитуры по семействам, сверка с конфигуратором Blum (первое: MOVENTO + TIP-ON BLUMOTION).
2. Готовые узлы: модели описываются файлом.
3. Конвейер на модель с проверками и разбором ChatGPT.
4. Передача цеху: формат Базиса через BXF (после пробной версии) или PDF + CSV.
