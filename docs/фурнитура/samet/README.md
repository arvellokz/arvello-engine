## Чего здесь нет
- Нагрузки в кг для этой серии в каталоге нет.
- Зазоров между фасадами для Push-Open здесь нет. В инструкции Smart Slide Single (manualslib) — не меньше 2,5 мм, но это другая серия, для full | Power проверить.
- MILAT (наши «эконом» и «стандарт») — документов производителя не найдено. В чертёж не ставить, пока нет паспорта.
