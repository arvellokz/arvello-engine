# ENG-002 · Пример новых листов: один ящик комода ARV-NST-101

Файл: `ARV-NST-101_ящик_ENG-002.pdf` (6 листов A3). Генератор: `tools/eng/eng002_drawer.py`; тест: `tools/eng/test_eng002.py`.
Исполнение: 1200, нажатием, со столиком, NL 480. Данные — из той же модели, что и комплект.
Статус: **пример, не утверждено, не для изготовления, цеху не отправлять.** Исправлен 12.11 по проверке Codex.

Запуск:

    python3 tools/eng/eng002_drawer.py out.pdf [width=1000|1200] [changer=yes|no]

Генератор проверяет каждый рисунок: точка крепежа ставится только там, где видна сторона, с которой его вкручивают, и эту сторону не закрывает другая деталь. Если нет — `FAIL`, и пример не выпускается.

## Что подтверждено, а что проверить

| Утверждение | Метка | Основание |
|---|---|---|
| Размеры деталей 470 × 150, 526 × 121, 536 × 470; паз 16 × 5 на 13 | [М] | Наша модель. Для NL 450 совпадает с раскроем конфигуратора Blum 12.11 [Д] |
| SKW = LW − 42 +0 / −1,5; SKL = NL − 10 | [Д] | Blum TD-132, каталог |
| Крепёж 8 / 6 / 4; вход самореза фасада 9, до лица 9; фасад вплотную к стенке | [М] | Модель; проверки `verify_new` п. 15 и рисунков |
| Направляющие 760H4800S, замки T51.7600, TIP-ON T60L7340, синхронизация LW − 267 = 301 | [Д] артикулы; [О] комплект | `docs/blum/` |
| Места саморезов профиля 19 / 37 / 69 / 243 / 261 / 293, ось 38 | [Д] | Каталог Blum 2024/25 с. 428 |
| Замки: у передних углов, зона 75 от боковины | [Д]; [О] по шаблону | `docs/blum/`, рис. 76XHSK_H_1 |
| Крючок: Ø6, гл. 10, 7 от заднего торца, 11 по высоте | [Д] числа; сторона и база не подтверждены — **заблокировано** | `docs/blum/`, SVG 76XHSK_H_2; Var1 = 125 не используется |
| Зазор дна в пазу (сейчас 0) | [М] — не согласовано | Ц-4; проба заблокирована |
| Засверловка под саморезы дна | [М][С] | Ц-5 |
| Кто сверлит крючок и замки | не назначено | Ц-12 |
| Фиксация, TIP-ON, зазоры фасада; понятность рисунков | [О] | Проба 2 (Ц-11): рабочий ящик в тестовой секции |

## Ограничения

- Рисунки косоугольные, без масштаба. Профиль MOVENTO и замки — схематично, не контур Blum.
- Это демонстрация на одном ящике. Инструкция на весь комод (корпус, стойки, 6 ящиков, направляющие, фасады, стена, столик) — после проб (план П1).
- Рисунки IKEA визуально не сопоставлены: PDF недоступен из среды.
