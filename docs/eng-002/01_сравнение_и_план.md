Это демонстрация подхода на одном ящике, а не готовый комплект комода и не закрытие ENG-002.

> **Решение владельца 12.11 «независимость от цеха» (действует поверх текста ниже).** Технологические параметры Arvello задаёт сама по общепринятым нормам: `tools/eng/cab.py`, `TECH` — паз под дно 16,5 × 5, зазор дна 0,5 на сторону, засверловка Ø3 гл. 8 под 4 × 25, крючок и замки сверлит сборщик по шаблону T65.1000.02. Вопросов цеху — 4 (`03_вопросы_цеху.md`): формат заказа; готовые размеры с кромкой; проба деталей одного ящика; файл для станков (BXF или DXF).

Метки достоверности — четыре уровня, они не заменяют друг друга:
- **[М]** — заложено в нашей модели генератора. Это наше решение, а не независимое подтверждение.
- **[Д]** — подтверждено независимым документом: руководство БАЗИС (прочитанные разделы) или данные Blum в `docs/blum/` со ссылкой.
- **[С]** — проверить на станке и в программе цеха.
- **[О]** — проверить на пробном образце.
- **[?]** — нет данных, нужен ответ цеха (вопросы Ц-n в `03_вопросы_цеху.md`).

Размеры деталей, допуски и разделение операций «цех / сборщик» помечаются [М], даже если их проверяет генератор. [Д] ставится только при ссылке на документ производителя.

## 3. Путь передачи цеху: что известно и как проверить

1. **[Д, в пределах прочитанного]** Гл. 3 описывает выпуск комплекта из модели БАЗИС: сборочный чертёж, чертежи панелей, таблицы операций, спецификация. Если цех работает так, ему нужна модель в БАЗИСе. Есть ли другие пути, руководство (прочитанные разделы) не говорит.
2. **[?]** Как модель появится в БАЗИСе:
   - **(а)** цех строит её сам по нашим PDF — ручной ввод, источник ошибок;
   - **(б)** импорт нашего файла: формат и возможность не подтверждены. BXF — не считать форматом БАЗИС без пробного импорта;
   - **(в)** цех кроит по нашему списку деталей (CSV / XLS) в своей программе раскроя, а присадку делает по нашим PDF.
3. **[?]** Станочные файлы (раскрой, присадка, пазы) формирует цех на своём оборудовании. Мы их не обещаем; формат узнать (Ц-3).
4. **Проба (предложение), два этапа (Ц-11):**
   - **Проба 1 — обработка деталей:** 5 деталей короба одного ящика. Отправляем PDF (лист Ц + листы деталей), CSV деталей и, если цех скажет, другой формат. Цех вводит или импортирует детали, кроит, кромит, сверлит, фрезерует паз и записывает **каждое ручное исправление**. **Заблокирована** до согласования посадки дна в паз (Ц-4) и засверловки (Ц-5).
   - **Проба 2 — рабочий ящик:** короб + фасад + направляющие, замки, TIP-ON BLUMOTION в тестовой секции корпуса. Сборщик, который не видел чертежей, собирает по листам С1–С5 без пояснений автора. Проверка: фиксация замков, ход, открывание нажатием, зазоры.
   - Все правки возвращаются в генератор. Только после этого — инструкция на весь комод и решение владельца.

| Последовательность | Обложка → предупреждения пиктограммами (опрокидывание, один ящик) → инструмент → «как работать» (мягкая подложка, вдвоём, звонить при вопросах) → инвентарь по **пакетам** → 62 шага. Корпус → крепление к стене → ящики группами → установка ящиков в корпус по карте → снятие ящика |
| Крупность | A4 книжный, 1–2 шага на странице, номер шага крупный. **Одно действие — один рисунок**, почти без текста |
| Детали | Деталь в положении сборки. Уже собранное — светлое, новая деталь — тёмная или серая. Направление установки — стрелкой. Похожие детали различаются наклейками на детали (L1 / L2 / R1 / R2), наклейка нарисована |
| Крепёж | Крупный выносной круг с местом соединения: крепёж в натуральную величину, отверстие входа, направление вращения инструмента, «N×» и номер крепежа. Пакет, из которого брать, — значком на шаге. Где ошибаются — пара «правильно / неправильно» (перечёркнуто) |
| Количество | «N×» у каждого крепежа на каждом шаге. Повторы — рамкой перед группой шагов («2×», «1× + 3×» с картинкой, каких ящиков это касается) |
| Предустановка | Крепёж вставляется в деталь до соединения (отдельный шаг) |
| Контроль | Мало текста. Важное — пиктограммой (проверить блокировку, не открывать два ящика). Карта: какой ящик в какой проём |
| Стена | Отдельная страница: тип стены (бетон / пустотелая / дерево) → сверло и крепёж |
