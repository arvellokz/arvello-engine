# ENG-002 · Комплект для цеха по правилам руководства БАЗИС

Дата: 13.11.2026. Решение владельца: оформление листов для цеха — по руководству «Создание документов с модели» (БАЗИС, 16.04.2026), чтобы цеху на БАЗИСе было привычно. Применено к новым моделям: комод ARV-NST-101 и шкаф ARV-WRD-101. 36 старых моделей не менялись.

Статус: инженерное предложение R01E, **не утверждено, не для изготовления**.

Код: `tools/eng/bazis.py` (листы и проверки), `tools/eng/kit13.py` (сборка комплекта). Тест: `tools/eng/test_bazis.py` — для каждого правила негативный случай.

Где руководство зависит от цеха, взят типовой вариант руководства как наше значение [М] (`cab.TECH`), проверка — пробой [О]:
- порядок операций: раскрой → облицовка кромок → присадка (БАЗИС с. 38);
- размеры отверстий — от облицовки, база A — угол готовой детали;
- припуск на фуговку — 1 мм на облицованную сторону;
- порядок облицовывания — короткие → длинные.

Также по замечаниям журнала:
- лист «Сборка и контроль» комода: крепление к стене — до направляющих и ящиков, с числом уголков из спецификации (проверка + негатив);
- источник Blum для направляющих: артикул — каталог 2022/23 стр. 436 и конфигуратор; места саморезов — каталог 2024/25 с. 428.

Объём: комод со столиком — 31 лист, шкаф 2400 × 2800 — 42 листа. Все листы просмотрены.
