# Arvello — состояние проекта (на 28.10.2026)

Мебельный бренд в Алматы: 2 владельца, бюджет 3 млн ₸. Arvello продаёт мебель и ведёт заказ, а изготавливают её сторонние ручные цеха.
**Цех ничего не предоставляет: Arvello сам даёт цеху полное задание** (чертёж, спецификацию материалов (BOM), фурнитуру, допуски, требования приёмки). Конструктора не нанимаем: конструкцию берём из открытых источников, где разрешено продавать изделия, а дизайн делаем свой.

## Ключевые решения
- Артикулы ARV-КАТ-NNN. Категории: KIT, BED, NST, WRD, LIV, TBL, BTH, OFF. Форматы продукции: STD / CFG / IND.
- Цвета: W — белый, C — кашемир, G — графит, O — дуб. Металл: чёрный или белый.
- Цена = себестоимость / (1 − маржа). Себестоимость = материалы (расход × (1 + отход)) + комплектующие + операции по прайсу за результат + логистика, плюс резерв. Сайт считает по максимальной ставке среди активных цехов. Округление — вверх до 1 000 ₸ (в коде).
- В админке одно действие выдаёт сразу несколько заданий: поставщику, цеху, камнерезам.
- Фото карточки: hero на белом фоне первым, затем спереди, сбоку, деталь и одно фото в интерьере; формат 4:5.
- Источники чертежей: конфигуратор Blum и Ana White. Rogue Engineer и Kreg не используем.
- «Нимб» v2 (сталь): отступ основания 200 мм, опрокидывание ≈258 кг на краю. «Нимб Wood»: отступ 140 мм, просвет 145 мм, ≈300 кг на углу изножья.
- Генерация фото (28.10): этап 1 — владелец запускает скрипты у себя и загружает site_images в админку («Импорт фото»); этап 2 — генерация из админки на сервере (очередь задач, отбор вариантов в админке, ключ API на сервере). Вариант без hero (ready: false) на сайте не показывается; после правки геометрии модели её фото помечаются «устарели».

## Сайт: решения по ТЗ (27.10)
- Сайт и админку делает Claude; код в приватном репозитории GitHub владельца, выкладка через GitHub Actions. Пароли и ключи — в секретах GitHub, не в чате.
- Языки: русский и казахский (сайт, кабинет, письма, КП, счета). Казахский вычитывает владелец (носитель). Задания и чертежи для цехов и админка — на русском.
- Фирменный стиль: логотип «Парение», шрифт сайта Montserrat, фон #ECEAE5, поверхности #FFFFFF, текст #2E3033.
- Учётные записи: клиент — физлицо (телефон + пароль, код из SMS) или компания (реквизиты в кабинете); партнёрам логин и пароль выдаёт владелец.
- Покупка: физлицо — корзина и онлайн-оплата; компания — КП и счёт по реквизитам.
- Замер платный, 5 000–10 000 ₸, при заказе вычитается из стоимости.
- Видимость: на старте вручную (товары, материалы, механизмы, опции), система предупреждает; автоматический режим — позже.
- Протокол испытаний — необязательное поле.
- Стек: Next.js + PostgreSQL 16 + Three.js + model-viewer. Хостинг hoster.kz, Cloud 4-4-100 (≈12 400 ₸/мес без НДС), Ubuntu 24.04.
- Этапы: 0 подготовка → 1 «Сайт продаёт» → 2 «Ведёт производство» → 3 «Рост».
- Ждёт подтверждения: IND без конструктора, предоплата 50%, кухня на этапе 1 без ручной расстановки модулей, расчёт 14 дней, AR на этапе 2, ARV-BED-004 для «Нимб Wood».
