# Приложение А к ТЗ сайта: опции конфигуратора и 3D для клиента

Версия 1.0, 08.11.2026. Дополняет claude/arvello-site-tz.md (раздел 6 «Страница товара», пункт 13 «3D для клиента»). Основа: опции всех моделей, считанные с arvello.kz 08.11, и практика производителей офисной мебели.

Статусы: ЕСТЬ — опция уже на сайте; ПЕРЕИМЕНОВАТЬ — есть, но название непонятно клиенту; ДОБАВИТЬ — нет. Каждая новая опция появляется у модели только после того, как цех назвал за неё цену (надбавка в админке, ТЗ раздел 8). Решение, какие опции включать, — за владельцем.

## А.0. Два разных шаблона страницы товара (найдено 08.11)
- Кровати и шкафы — новый шаблон: шаги «Основа, размер и цвет → … → Дополнения», панель «Итого», «Проверить выбор».
- Кухни, тумбы, столы, офис, гостиная, ванная — старый шаблон: блок «Соберите под себя», кнопка «Оформить в WhatsApp» с текстом «Номер WhatsApp скоро появится», «Поделиться конфигурацией», «Проверить выбор».
- Требование: один шаблон для всех моделей (новый, доработанный по ТЗ раздел 6), с лучшим из старого: «Поделиться конфигурацией» и кнопка WhatsApp.

## А.1. Общие правила опций
1. Название опции — словами клиента, с пользой: не «Экран: по заднему краю», а «Экран под столешницей — закрывает ноги от сидящих напротив».
2. У опции, меняющей вид, — маленькая картинка или схема; у опции, меняющей цену, — «+N ₸».
3. Опции, которые клиент не видит (доводчики, класс фурнитуры), — флажками с одной строкой пользы («ящики закрываются мягко и бесшумно»).
4. Подсказка «Для кого» у спорных опций (например, высокое основание кровати — «удобнее вставать»).
5. Опции по умолчанию — самый популярный вариант, а не самый дешёвый.

## А.2. Офисные и рабочие столы — главное
Модели: «Модуль» OFF-001, «Фокус» TBL-004, «Руководитель» OFF-007, бенч «Ряд» OFF-002, «Совет» OFF-003, «Приём» OFF-004, «Студент» TBL-002.

### Экран под столешницей (царга-экран, modesty panel)
Закрывает ноги сидящего от людей напротив и сбоку — важно в офисе, особенно для сотрудниц в юбках и на ресепшн; заодно прячет провода и системный блок. У производителей такая панель обычно опускается ниже столешницы примерно на 25–45 см (например, 10–11,75″ у Workrite, до 18″ у Fellowes).

| Модель | Сейчас | Что сделать |
| --- | --- | --- |
| «Модуль» OFF-001 | ЕСТЬ: «Экран: нет / по заднему краю» | ПЕРЕИМЕНОВАТЬ в «Экран под столешницей: нет / спереди / спереди и по бокам»; добавить глубину экрана «до колен (≈30 см) / почти до пола (≈45–60 см)» |
| «Фокус» TBL-004 | нет | ДОБАВИТЬ те же варианты |
| «Руководитель» OFF-007 | на панельных опорах, фронтальной панели в опциях нет | ДОБАВИТЬ «Экран спереди: нет / есть» — для кабинета с посетителями по умолчанию «есть» |
| «Совет» OFF-003 | нет | ДОБАВИТЬ «Экраны по длинным сторонам: нет / есть» (переговорные с короткими юбками напротив — та же проблема) |
| Бенч «Ряд» OFF-002 | «экраны» в описании без уточнения | Разделить: «Экран между местами над столом» и «Экран под столом (по краю ряда)» |
| «Приём» OFF-004 | борт 1100 закрывает сотрудника спереди | Проверить боковые стороны: «Боковые панели до пола: да / нет» |

Материал экрана: «как столешница» / «металл перфорированный в цвет каркаса» / позже «акустическая ткань».

### Экран над столешницей (перегородка)
Для опенспейса: «нет / 30 см / 40 см над столом», материал ЛДСП или акустическая ткань. Не путать с экраном под столом — на сайте это две отдельные опции с разными картинками.

## А.8. Гостиная и ванная
- ТВ-зона «Экран»: длина, панель (ЕСТЬ); ДОБАВИТЬ «Диагональ ТВ» (подсказка ширины ниши), «Скрытый канал для проводов», «Подсветка панели».
- Тумба «Поток»: ширина, цвет, металл (ЕСТЬ); ДОБАВИТЬ «Раковина: накладная / встроенная / без раковины», «Ящики: 1 / 2», строку «Влагостойкие материалы» (обязательно указать, из чего корпус и кромка — главный страх в ванной).

## А.9. 3D для клиента
1. Каждая опция, меняющая вид, видна в 3D. При выборе опции камера плавно поворачивается к ней:
   - экран под столешницей → вид со стороны посетителя, на высоте глаз сидящего (≈110 см), с фигурой человека, сидящего за столом: видно, что ноги закрыты;
   - экран над столом → вид сверху-сбоку на ряд мест;
   - подсветка → кнопка «Вечер» (затемнение сцены, подсветка светится);
   - подъёмный механизм, ящики, двери → анимация открывания по нажатию «Открыть»;
   - «до потолка» → показать линию потолка введённой высоты.
2. Фигура человека: стоящая 175 см для шкафов и кроватей; сидящая на стуле — для столов, стойки ресепшн и кухни (рабочая высота). Переключатель «Показать человека».
3. Сцена по умолчанию: пол со светлым паркетом, мягкая тень, стена сзади (у предметов у стены), постель на кровати, без инженерных деталей (ламели, присадка).
4. «Заглянуть внутрь» — только у шкафов, кухонь, тумб. «Только каркас» из клиентской версии убрать.
5. Размерные линии — по кнопке «Размеры», не по умолчанию.
6. На телефоне 3D открывается на весь экран кнопкой и закрывается свайпом вниз.

## А.10. Для админки
- У опции: название для клиента, короткая польза, картинка, «меняет вид» (да/нет — для ключа изображения), «меняет цену» и надбавка от цеха, доступна ли опция (переключатель).
- Опция скрыта, если цена надбавки не введена.
