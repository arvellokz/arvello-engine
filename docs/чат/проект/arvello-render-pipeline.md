# Arvello — конвейер рендеров (Blender)

Версия 2.0, 09.11.2026. Решения владельца: hero — рендер выбранной конфигурации; три уровня изображений (живое 3D → студийные кадры из Blender → ИИ только для интерьеров); кадры одобряет Темирлан; текстуры точечно не дорабатываем — конкретные декоры выбираются вместе с цехами, сейчас важна система (09.11).

## Что сделано (r1.1)
Пакет arvello-render.zip (отправлен владельцу 09.11): render.py, materials.json, catalog.json, README.md, папка textures/.
- Один скрипт рендерит любую из 36 моделей, любой вариант, любой ракурс карточки. Проверено на кроватях, кухне, столах, тумбе, комоде, шкафу, прихожей, ТВ-зоне — без ручной настройки.
- Геометрия — снимки ядра из 3D-каталога (детали в мм, те же, что в чертежах). Ламели под матрасом скрываются.
- Ракурсы hero / front / side / detail — из catalog.json → angles по категории (угол, высота, объектив, область крупного плана); камера сама подбирает расстояние, кадр 4:3.
- Свет — студийная схема, масштабируется по размеру изделия. Пол и стена (для навесной мебели) ловят мягкую тень на прозрачном фоне; итоговый фон #F7F6F2 (как на сайте). Подсветка LED включается сама по данным варианта.
- Материалы по индексу палитры (materials.json): однотонные — цвет + микрорельеф; дуб — процедурное волокно вдоль длинной стороны детали; ткани, металл, стекло, экран, зеркало. Скан декора подключается строкой в materials.json (texture + tile_mm) — без правки кода.
- Очередь: повторный запуск пропускает кадры с неизменным хешем (геометрия + материалы + ракурс + версия сцены). Поменяли модель или декор — пересчитаются только затронутые кадры.
- Выход: out/<артикул>/<вариант>/<ракурс>.png (прозрачный мастер), .jpg на #F7F6F2, -1200.webp и -2000.webp; out/index.json (хеш, файлы, дата, статус new → approved).
- Стилизация: у кроватей плед в изножье (не часть изделия).

## Время
Облачная среда Claude (CPU): ≈ 25 с черновик (800 px, 12 сэмплов), ≈ 2,5–4 мин кадр для сайта (1200 px, 32 сэмпла). Видеокарта Nvidia RTX — в 10–20 раз быстрее (cycles.device = GPU). Весь каталог hero для всех вариантов (≈ 550 вариантов) на CPU ≈ 1,5–2 суток; на RTX — несколько часов.
