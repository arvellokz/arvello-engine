# Arvello — чертежи и единый источник геометрии (на 29.10.2026)

Дополнение к arvello-status.md.

## Решение владельца (29.10)
- Единый источник геометрии — ядро в проекте генератора (arvello_visuals, tools/eng). Генератор ChatGPT для «Опоры» (пакет R02-E) — материал для переноса правил и проверок, не второй источник.
- Неподтверждённые решения не попадают в каталог: они хранятся как отдельная инженерная ревизия.
- Документы делятся на два уровня: «что» (вид, размеры, материалы, устойчивость, приёмка — задаёт Arvello) и «как» (узлы, крепёж, технология — согласуется с цехом и фиксируется в новой ревизии). Цеху сначала короткий пакет для оценки, рабочие чертежи — после согласования технологии.
- Автоматизируется выпуск документов по проверенным правилам; разработка и проверка конструкции — один раз на модель (образец в цеху).

## Как устроено (tools/eng)
- Снимок конфигурации = изделие + ревизия + опции + детали, с хешем. Из него: 3D, фото (отпечаток геометрии), чертёж PDF, спецификация, раскрой, состав затрат. Цены — catalog/prices.json, в хеш не входят (сейчас пример, не реальные цены).
- catalog/revisions.json — какая ревизия идёт в каталог. «Опора»: каталог R00 (рамы на полу, без связей), инженерная R02E (связи, пластины, подпятники h=35 — не утверждено).
- Смена каталожной ревизии → tools/stale.py помечает фото «stale: true». Заказ замораживается (tools/eng/freeze_order.py): папка orders/ORD-… только для чтения, не пересчитывается.
- 7 проверок: R02E совпадает с пакетом R02-E (рама 690, стойка 610, связь 1220, труба 7680, остатки хлыстов 109/4141), весь ряд 1200–2000, 3D = чертёж = спецификация = затраты по деталям, каталог использует ядро.
- Сквозной пример (страница): https://claude.ai/artifact/EzGRAMrM7B9Bv4nrC8TKDa
