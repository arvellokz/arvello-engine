# Пример карточки дизайна: ТВ-тумба (образец заполнения, не утверждено)

Это образец, как заполнять. Модель условная — настоящую выбирает владелец по трендам.

1. **Артикул и название:** ARV-LIV-101 ТВ-тумба «…» (название — владелец).
2. **Откуда идея:** ссылка на пример 1, `liv101_ref1.jpg`; пример 2 — для ручек, `liv101_ref2.jpg`.
3. **Чем цепляет:** два цвета — тёмный корпус и дубовые фасады с рейками; лёгкая, на тонких ножках.
4. **Габарит:** 1600 × 400 × 550 (корпус 400 + ножки 150). Клиенту: 1400 / 1600 / 1800.
5. **Как стоит:** 4 ножки 150, металл чёрный, конус Ø30 → Ø15 (≈ по картинке).
6. **Сетка фасада** (спереди, слева направо):
   ```
   [ 500: ящик во всю высоту ] [ 600: открытая ниша, полка посередине ] [ 500: ящик во всю высоту ]
   ```
7. **Фасады:** накладные, зазор 3; на фасадах ящиков вертикальные рейки 20 × 16, шаг 30 (вместо рифления).
8. **Ручки:** комфорт — без ручек, нажатием; эконом / стандарт — скоба 192 мм, латунь, по центру у верхнего края.
9. **Цвета:** корпус «Графит 3114»; фасады и рейки «Дуб Бунратти 4069»; ножки чёрные.
10. **Наполнение:** 2 ящика, полка в нише, ввод кабеля Ø60 в задней стенке ниши.
11. **Особая деталь:** рифлёный фасад → рейки ЛДСП 20 × 16 с шагом 30.
12. **Опции для клиента:** ширина, декор корпуса, декор фасадов, уровень фурнитуры.
13. **Цена ориентира:** ≈ 250 000 ₸ (магазин …, ссылка).
14. **Сомнения:** ножки 150 или 200; держит ли рейка на фасаде ящика (вес).
