# Точные данные Blum без угадывания

Правило: данные фурнитуры — только из документа производителя или конфигуратора Blum, со ссылкой (страница, файл, артикул). Не читаемо — открытый вопрос, не догадка. Результат — markdown в `docs/blum/` репозитория + копия в Obsidian `Обмен/ENG/Blum`.

## 1. Конфигуратор изделий (e-services.blum.com/opc)
- Входит владелец (пароли не вводить). Использовать конфигуратор **изделий**, не корпусов.
- Поля: JS, нативный сеттер `value` + события input, change, focusout; после каждого поля искать элементы заново.
- Переключатели SAP UI5 (role=switch): только реальный клик по координатам; 1 CSS px ≈ 1,25 px скриншота. Узкая панель: resize_window 1500×950, после — preset desktop.
- Если после «Назад»/перезагрузки ошибка или вечная загрузка — не бороться, брать данные из сетевого ответа (п. 2).

## 2. Сетевой ответ вместо PDF
Скачивание во встроенном браузере блокируется. Вместо отчёта:
- `read_network_requests` во вкладке конфигуратора, найти `PAI036/api/functionalunits/<id>/loadPlanningResult`, прочитать тело по requestId: раскрой ящика (cuttingList), артикулы (itemList), ссылки на DXF/DWG/SVG/GIF всех рисунков (planningInformation) и подписи переменных (svgVariables).

## 3. DXF и SVG с d2.blum.com
- Открыть любую вкладку на `https://d2.blum.com/...` (например, GIF рисунка) и делать `fetch` там (тот же источник). Из песочницы домен закрыт.
- DXF: разобрать пары код/значение; секция ENTITIES: CIRCLE (10/20 центр, 40 радиус) = отверстия; LINE — контуры; DIMENSION — размер, его подпись лежит в блоке `*D…` секции BLOCKS (код 1). Выводить только числа, не весь файл.
- Проверить масштаб 1:1 по известному подписанному размеру. X отверстий давать от передней кромки боковины.
- SVG: `DOMParser` → тексты `<text>`; сам рисунок — открыть URL во вкладке и сделать скриншот.

## 4. Каталог Blum 2024 (publications.blum.com/2024/catalogue/en/)
- Текстовый слой: `files/assets/common/page-vectorlayers/NNNN.svg`, NNNN = печатная страница + 4. Тексты с координатами (transform matrix e, f) — сортировать по Y для строк таблиц.
- Поиск: пройти диапазон страниц fetch-ем пачками по 12 и искать артикул/слово.
- Значки (◐ ○) есть только на растре `page-html5-substrates/pageNNNN_3.webp`: открыть SVG-страницу во вкладке, вставить `<image>` растра первым элементом, ширину SVG поставить 3000–9000 px, прокрутить `scrollTo` и сделать скриншот.
- Легенда крепления направляющих: A (саморезы) = все места ○ и ◐; B (системные винты Ø6) = только ◐; * — можно заменить саморезом; ** — по желанию.
- Страницы: MOVENTO крепление 428; TANDEM 560H 460, с TIP-ON 528; петли CLIP top 76–77; планки 150–156; TIP-ON дверей 192–193; крепёж 160.

## 5. Известные ловушки
- 173H7100 — планка под саморезы Ø3,5/4; с предустановленными евровинтами Ø6 — 173L8100 (Ø5, 37 от кромки, 32 между).
- Размеры 45 / 9,5 у петли — с рисунка INSERTA/knock-in; у screw-on Blum их не образмеривает.
- Точка 28 в таблице есть только у 766H, у 760H — нет.
- +1 мм к оси 38 Blum требует только если профиль ставят до сборки корпуса.
- Документ сайта-агрегатора — не источник; источник — Blum.
