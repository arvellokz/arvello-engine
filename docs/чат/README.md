## Как запустить второй аккаунт (владельцу, 5 минут)
1. claude.ai → Настройки → Коннекторы: подключить GitHub с доступом к `arvellokz/arvello-engine`. Desktop-приложение — то же, что и раньше (для Obsidian и браузера).
2. Создать проект «Arvello», загрузить в него `arvello-engine-handoff.md` и `arvello-know-how.md` (и при желании `проект/arvello-strategy.md`, `проект/arvello-kagan.md`).
3. Настройки → Навыки (Skills): создать два навыка из файлов `навыки/` (имя и описание — в шапке каждого файла).
4. Первое сообщение в новом чате проекта:
   > Прочитай файлы проекта, затем в arvellokz/arvello-engine: HANDOFF.md, docs/чат/README.md и последние 10 записей docs/ЖУРНАЛ.md. Продолжаем.
5. Claude Code во втором аккаунте: `/login` вторым аккаунтом, затем `claude --continue` в папке репозитория — сессия кода продолжит с того же места (её память — в репозитории).

## Как проверить, что перенос сработал
Спросить новый чат: «что сейчас с комодом и что ждём от меня?». Правильный ответ: выпуск ENG-002 проверен, замечания закрыты, комод готов к отправке цеху с 4 вопросами; от владельца — отправка цеху, проба ящика, пробный БАЗИС.
