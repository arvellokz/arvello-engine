## Правила (не нарушать)
- R01E — «не для изготовления», ничего не помечать утверждённым. Цены не придумывать.
- Данные фурнитуры — только из документов производителя / конфигуратора Blum со ссылкой (`docs/blum/`), не угадывать по картинке.
- Пароли не вводить (в Blum и админки входит владелец). Сообщения цеху и клиентам не отправлять — готовить текст, отправляет владелец.
- Скачивание файлов — с разрешения владельца. Встроенный браузер скачивание блокирует: DXF/SVG Blum читать через fetch во вкладке на d2.blum.com; каталог Blum — текстовый слой `publications.blum.com/2024/catalogue/en/files/assets/common/page-vectorlayers/NNNN.svg` (NNNN = страница + 4).
- Email владельца приватный — в файлы репозитория и внешние сервисы не писать. Public-артефакты не обновлять без явного «да».
- Obsidian: `C:\Users\user\Documents\ChatGPT\Arvello\Arvello-HQ` (через device_* инструменты; доступ к папке запрашивается заново в каждом аккаунте/сессии).

## Выпуск для цеха (ENG-002)
- Один набор: `docs/eng-002/выпуск/` — A3 цеха (комод со столиком 31 л., без столика 26 л., шкаф 2400×2800×450 47 л.), A4 сборщика (комод ×2, ящик), пример A3 ящика, CSV «детали и покупные» ×3, `МАНИФЕСТ.md` (снимок модели, у всех файлов исполнения один).
- Собирается одной командой: `python3 tools/eng/eng002_kit.py`. Отдельно: `kit13.py ARV-NST-101 out.pdf width=1200 handle=push changer=yes color=O`, CSV — `export_parts.py`.
- PDF выпуска держим в репозитории (это и есть то, что получает цех). Копия — Obsidian `Обмен/ENG/ENG-002/выпуск/`; старые папки там помечены `УСТАРЕЛО.md`.
- Шрифт листов — DejaVu Sans из `tools/eng/fonts/`, вкладывается в PDF; без него генератор останавливается (раньше на Windows подменялся и строки вылезали за рамку).
- Тесты: `test_nst101.py`, `test_wrd101.py`, `test_bazis.py`, `test_eng002.py`, `test_fonts.py` — при расхождении код возврата 1; `check_catalog.py technical` — 0 нарушений (6538 вариантов).
