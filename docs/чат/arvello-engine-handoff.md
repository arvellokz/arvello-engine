## Правила (не нарушать)
- R01E — «не для изготовления», ничего не помечать утверждённым. Цены не придумывать: оценки помечать как оценки, с источником.
- Данные фурнитуры — только из документов производителя со ссылкой (`docs/фурнитура/`, `docs/blum/`), не угадывать по картинке.
- Пароли не вводить (кабинеты ДСП Центра, Blum, админки — входит владелец). Сообщения цеху и клиентам не отправлять — готовить текст.
- Кабинет ДСП Центра: только «Сохранить черновик» / «Сохранить и раскроить», «Оформить» не нажимать.
- Скачивание файлов — с разрешения владельца. Из рабочей среды многие сайты закрыты: скачивать через Chrome владельца в «Загрузки», затем забирать (device_stage_files).
- Email владельца приватный. Public-артефакты не обновлять без явного «да».
