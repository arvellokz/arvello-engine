# Arvello Engine — передача работы (12.11.2026)

Генератор чертежей корпусной мебели Arvello. Из одной модели изделия выпускаются: комплект чертежей A3 (PDF), деталировка и покупные (CSV), 3D-снимок, проверки. Работа перенесена сюда из общего чата Arvello (claude.ai), чтобы вести её как проект с историей изменений.

## Кто и как

- Владелец — Темирлан (Arvello, Алматы). Отвечать по-русски, просто, без жаргона; владелец не инженер.
- Производство — цех-партнёр (Kagan.kz). **Технолога нет:** цех делает строго по чертежу. Значит, в чертеже не должно оставаться решений «на усмотрение цеха»; от цеха нужны только факты (оборудование, материалы).
- Фурнитуру цех **в цену не включает**: Arvello покупает её сам у поставщиков. Выбор марки (Blum / аналоги) не сделан — его надо исследовать (цены, отзывы, наличие в Алматы) и, вероятно, сделать опцией конфигуратора.
- Второй проверяющий — ChatGPT: разбирает каждый выпуск, его разборы лежат в `docs/reviews/`. Каждое подтверждённое замечание превращается в постоянную автопроверку.
- Цех спрашивал, можно ли прислать файл в формате **Базиса** для раскроя. Путь: Базис импортирует корпуса Dynaplan/Blum в формате BXF (XML). Проверить на пробной версии Базиса (14 дней, владелец рассматривает заявку). Свой родной формат Базиса закрыт.

## Правила (не нарушать)

- Ревизия R01E = инженерное предложение, **не для изготовления**, пока цех не проверил образец.
- Цены не придумывать. Металл и обивку не проектировать.
- Данные фурнитуры — только из документов производителя или конфигуратора Blum, со ссылкой. Не угадывать по картинке; если не читается — открытый вопрос.
- Коды декоров и артикулы, которые не подтверждены, — кандидаты в открытых вопросах.
- Модели 36 старых не удалять; новые — в `tools/eng/models_new.py` (реестр `NEW`).
- Изменения общего ядра (`cab.py`, `kit13.py`) должны проходить `check_catalog.py technical` с 0 нарушений.
- Пароли не вводить; файлы для цеха и клиентов пересылает владелец.
- После каждой модели: обновлённый архив ядра и комплекты — владельцу (и в Obsidian `Обмен/ENG`).


## План (согласован с владельцем 12.11)

1. **Справочник фурнитуры.** Для каждого семейства (MOVENTO, TANDEM, петли CLIP top, TIP-ON для дверей, подъёмники) — правила-формулы от LW / NL / размеров двери: отверстия, раскрой ящика, артикулы. Источник — конфигуратор Blum (см. `docs/blum/`), сверка 5–10 конфигураций на семейство, отметка «сверено». Неверенное не попадает в производственную ревизию. Аналоги (Boyard, GTV, Hettich) — тем же способом, когда выберем.
2. **Готовые узлы** (корпус, секция, колонна ящиков, дверь, антресоль, цоколь, кухонный модуль): новая модель описывается коротким файлом, а не кодом с нуля.
3. **Конвейер на модель:** описание → сборка → все проверки → просмотр всех листов → разбор ChatGPT → выпуск. Рисунки для сборщика (корпус → ящик в разнесённом виде → направляющие и фасады → надстройки).
4. **Передача цеху:** BXF/Базис (после пробы Базиса) или PDF + CSV.
